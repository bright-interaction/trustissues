# Substrings exempted from the mirror pre-flight secret scan.
# One per line, each with the reason it is provably synthetic.
# Anything real must be purged from history, never allowlisted.
#
# Trustissues needs more of these than the other mirrors, for a structural reason:
# it is a secrets manager whose tests must exercise real credential SHAPES, and it
# ships Shield, a PII/secret redactor that can only be tested by feeding it strings
# indistinguishable from live secrets. Every value below was verified to appear in
# ZERO non-test files, and the authoritative gitleaks gate over the filtered clone
# allowlists the same test paths.
